# Title

Template PDF renderer (reportlab + ArUco marker images)

# Summary

Render the printable A4 template PDF from a `TemplateLayout`: fiducial markers, cell grid with
per-script guides, labels, header with instructions and scale ruler — per DESIGN §7.1.

# Context

This is the physical interface of the product. Print fidelity (true-scale mm, crisp markers,
guides light enough to not survive binarization) directly determines ingest robustness.

# Scope

`packages/core/src/glyphlab/template/pdf.py` + orchestrator in `template/__init__.py`:

# Detailed Requirements

1. Use `reportlab.pdfgen.canvas` with `pagesize=A4` and `units.mm` throughout; no scaling
   transforms (print at 100% must equal layout mm).
2. ArUco markers: generate with `cv2.aruco.generateImageMarker(getPredefinedDictionary(
   cv2.aruco.DICT_4X4_50), id, sidePixels=280)`, wrap as PNG (Pillow) in-memory, place with
   `drawImage` at the §7.1 marker rects. Pure black on white; include the mandatory quiet
   zone (white border ≥ 2 modules) *inside* the 14 mm rect: renderer constants
   `MARKER_INK_MM = 10.5`, `MARKER_QUIET_MM = 1.75` live in `pdf.py` (renderer-specific;
   `layout.py` owns only the 14 mm rect).
3. Cells: 0.3 pt 60%-gray border on the writing box; label strip above with the target char
   (font: embedded NotoSansJP subset? NO — avoid font-embedding complexity: use reportlab's
   built-in `HeiseiKakuGo-W5` CID font for kana labels and Helvetica for ASCII; both are
   viewer-provided standard CID/Type1 fonts — document that labels are reference-only) at 12 pt
   45% gray + `U+XXXX` at 6 pt.
4. Guides inside writing box per §7.1: latin baseline/x-height rules (20% gray, 0.2 mm, dashed
   1.5/1.5 mm); kana centered square (20% gray, dashed). Guides must be ≥ 25% lighter than
   typical pencil so Otsu binarization drops them (verified end-to-end in 09/12 tests).
5. Header band: project name — apply §7.3/§17.4 in this function even though config already
   validates (defense in depth): strip C0/C1 control chars, truncate to 64 chars — then
   `{charset_id}@{version}` (e.g. `ja-basic-v1@1`), page `k+1/N`, template_id 8-char
   prefix, instruction line (Japanese):
   「太めのペンで、枠内の薄いガイドに合わせて書いてください。印刷は必ず100%（実際のサイズ）で。」
   and a 50 mm scale ruler with tick marks + "50mm" caption.
6. Output: one PDF per charset (multi-page) at `template/<charset_id>.pdf`; sidecar written via
   issue 07 API with the same `template_id` (uuid4 supplied by caller for determinism in
   tests).
7. Determinism: construct the canvas with `invariant=1` (reportlab's deterministic mode:
   fixed timestamps/IDs); a test asserts two generations with the same `template_id` are
   byte-identical. If a reportlab version regression breaks invariance, the byte test may
   be replaced by the raster golden test — record that decision in the PR description.

# Acceptance Criteria

- [ ] `ja-basic-v1` renders 6 pages; PNG rasterization of page 0 at 150 dpi via
      **pypdfium2** matches the committed golden (`packages/core/tests/artifacts/
      template-page0.png`, regenerated by `uv run python -m tests.template.update_golden`)
      with mean absolute pixel diff ≤ 2/255.
- [ ] Byte-identical PDFs across two runs with fixed `template_id` (invariant mode).
- [ ] Marker rects decode: rasterize page 0 at 300 dpi and `ArucoDetector.detectMarkers` finds
      IDs {0,1,2,3} at expected corners within 3 px (this closes the loop with issue 11's
      detector before real scans exist).
- [ ] Guides render lighter than 55% gray in the rasterized page (sample pixel assertions).
- [ ] Header-name hardening: `project_name` of 100 chars incl. `\x07` renders truncated to
      64 with control chars stripped (rasterized header contains no glyph anomalies; assert
      via the internal sanitizer unit test).
- [ ] PDF page size exactly 595.28×841.89 pt (A4).
