# 印刷・記入・撮影ガイド

A4普通紙・コピー用紙へ**100%（等倍）**で印刷してください。「用紙に合わせる」は無効にします。
ヘッダーの50 mmの目盛りを定規で確認します。デフォルト日本語セットは6枚です。

黒・濃紺の0.5〜1.0 mmのペンを使い、薄いガイドに合わせて書きます。鉛筆・シャープペンは
薄い線や反射が出やすいため推奨しません。枠や四隅のマーカーに触れないようにしてください。
失敗したら塗りつぶさず、新しい用紙へ書き直します。

撮影は明るい場所で、できるだけ真上から、ページ全体と四隅を入れます。影、反射、手ぶれを
避けてください。JPEG・PNG・HEICに対応し、1枚12 MiB・36 MPまでです。

- **かすれた文字**: 濃いペンで書き直し、明るい場所で再撮影します。
- **枠からはみ出した文字**: 縮小して書き直します。枠に触れた線は切れることがあります。
- **書き直した文字**: そのページを再アップロードします。採用済み文字は保護されるので、Webでは
  該当文字を却下してから再送してください。CLIでは意図した場合に `ingest --force` を使えます。
- **空欄**: 生成フォントにその文字は入りません。見本の欠落一覧で確認できます。
- **マーカーが見つからない**: 余白を切り取らず、四隅を含めて撮影します。

テンプレートを再生成した場合は、それ以前の用紙を廃棄して印刷し直してください。
異なるテンプレートの紙を混ぜると、マーカーだけでは区別できない場合があります。
