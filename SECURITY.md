# Security policy

The latest minor release is supported. Until the first stable release, report against
current main and include the tested commit and deployment configuration.

Report privately through [GitHub security advisories](https://github.com/Saber5656/glyphlab/security/advisories/new).
Do not include tokens or original handwriting in public issues. Hosted-instance abuse
reports are welcome; include times and non-secret project identifiers where useful.

The default coordinated disclosure period is 90 days, adjusted with the reporter when
needed. The [threat model](docs/DESIGN.md#17-security-model) describes the boundaries and
input limits. No user accounts or token-recovery mechanism exist in v1.
